# Battery SoH computational evidence — release candidate

**Status: recovered-artifact release candidate; not an accepted complete reproduction claim.**
Prepared for author inspection against the November 16, 2026 revision from the
tracked `main` snapshot `eb32c73`. No Git commit, tag, Zenodo deposit, or DOI
has been created by this package.

## What is actually preserved

- Final Step 11N first-3.6-V matched baseline study: 4,589 indexed test cycles,
  five model predictions for each test cycle, equality of labels, battery-level
  errors, HGB configuration searches, and paired-bootstrap results. Its compact
  archived input ZIP is included, so this specific experiment can be re-run
  without the historical 708 MB raw archive.
- Final Step 11O target-unrestricted study: 6,299 indexed constant-protocol
  cycles, five held-out model predictions per cycle, selected features and
  configurations from the saved workbook, stratified errors and paired
  battery-bootstrap results. All CSVs were extracted from the **preserved
  original result workbook**; the numerical models were **not retrained** here.
- Reconstructed **SoH percentage target values** for the 6,299 cycles and
  original 4,590-cycle age/target reference table (not a replacement for the
  missing per-battery capacity reference in Ah / raw charging records).
- Deterministic 10-fold outer and 90-fold inner battery split **designs**. These
  are reconstructed from the documented algorithm and actual held-out keys,
  not original training-execution event logs.
- The preserved reviewer workbooks for target reconstruction, main baselines,
  sensitivity, true censoring, sequence comparisons, transfer and screening.
- Seven generated figures, preserved byte-for-byte from available materials.

## Quick verification

From the repository root, with Python 3.10+:

```bash
python research_release/tools/verify_release.py
```

This checks SHA-256 for the released files, 4,589 / 6,299 keyed populations,
model set and target consistency, saved headline RMSEs and deterministic split
coverage. It does not re-run the full raw-to-prediction model pipeline.

## Running recovered experiment code

Install the existing nested Python project first:

```bash
cd battery_soh_reproducibility
python -m pip install -e .
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

For Step 11N (compact bundled inputs; runs nested baseline selection):

```bash
python scripts/experiments/step11n_matched_3p6v.py \
  --data-bundle ../research_release/inputs/step11n_frozen_input_bundle.zip \
  --output-dir outputs/step11n_recomputed
```

On PowerShell, put each command on one line instead of using bash `\` continuations.
Step 11N may be computationally substantial. The existing `results/step11n/`
files are preserved final outputs, not generated by the verification command.

For Step 11O, source reconstruction and model retraining require the **same
original raw archive** or an independently validated equivalent input export:

```bash
python scripts/experiments/step11o_target_unrestricted.py --help
```

The preserved original Colab exports live under `source_exports/`. The
repository-local Step 11O script adapts only source-directory resolution;
scientific training/evaluation functions are unchanged.

## Expected verification output

The checker prints independent equal-battery mean RMSEs from the saved
observation-level predictions. The final study's primary SoH percentage-point
results are Step 11N 3.6-V electrical/electrical+age HGB 2.282087/1.715947;
Step 11O unrestricted electrical/electrical+age HGB 2.288309/2.194821. The
SoH strata in Step 11O are diagnostic **after** model predictions.
