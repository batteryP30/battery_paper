# 2026-11-19 CALCE source-audit addendum — status update after v0.9.1

This addendum documents NEW post-v0.9.1 evidence. Statements in the previous NASA audit's console output saying “CALCE source rerun not verified” are **historical statements true when those older scripts and reports were produced**. They are superseded as to CALCE study-formatted XLSX-to-target verification by the evidence in `calce_xlsx_v1/`. The original reports remain preserved verbatim.

All eight CALCE source-workbook reconstructions passed, using 231 original study Excel workbooks held by the author in `collab.zip`. Six constant-protocol batteries yielded 5,686 candidate records, 5,663 raw-QC-valid labels, and 4,023 observations in the original 70–100% range; two variable-protocol batteries yielded 251 reference candidates, 238 eligible references, and 118 within the original 70–100% scope. All candidate records matched Step11A across all columns; all 5,663 constant-protocol QC-valid labels matched the saved Step11O archive with no missing keys and maximum target difference 1.4210854715202004e-14 SoH percentage points.

The author-controlled source files are identified by `calce_xlsx_v1/CALCE_Source_Workbook_SHA256.csv`, which lists 231 member paths, sizes, dates, and SHA-256 digests. These source files are not redistributed. To perform a NEW source-level reconstruction, run `research_release/notebooks/CALCE_Source_to_Target_Verification_Colab.ipynb` against the author's `collab.zip`. To recheck saved evidence without the large raw data archive, run `python research_release/tools/verify_current_editor_evidence.py --repo-root .`.

The source-workbook reconstruction does not prove the earlier instrumentation/logger-to-XLSX export, the original native NASA MATLAB-to-study-CSV conversion, or complete historical neural/HGB model refits. The older published v0.9.1 DOI `10.5281/zenodo.24365211` does **not** contain the CALCE addendum until a newer tagged release and Zenodo version are published.
